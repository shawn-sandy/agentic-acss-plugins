## Project patches

Four intentional divergences from upstream. Every refresh must re-apply these.

### P1 — `tokens/_color-semantic.scss` excluded

`sass/tokens/_index.scss` is project-authored. It forwards only
`_color-primitives`; it does **not** forward `_color-semantic`.

**Why:** The acss-kit OKLCH theme files (`light.css`, `dark.css`,
`brand-*.css`) generated by `/theme-create` and `/theme-brand` declare every
`--color-*` semantic role. Forwarding `_color-semantic` would silently
override those OKLCH values with the hardcoded blue/green/red defaults from
fpkit's upstream token file, breaking any custom theme a developer generates.

`_color-semantic.scss` is vendored (kept in `sass/tokens/`) for reference and
local inspection but is never imported.

### P2 — `_globals.scss` heading color

The `h1, h2, h3, h4, h5, h6` block in `sass/_globals.scss` has been patched
to add:

```scss
color: var(--color-text, #212529);
```

**Why:** The upstream heading rules set `font-weight`, `margin-block-*`, and
`line-height` but do not set `color`. Without this patch, headings inherit
browser default black (`#000000`) and do not respond to theme-defined text
colors. The `var()` with hardcoded fallback follows
`.claude/rules/scss-conventions.md`.

### P3 — Reduced-motion token collapse

The compiled `foundation.css` has a project-authored `@media
(prefers-reduced-motion: reduce)` block appended **after** the `@layer
foundation { }` wrapper:

```css
@media (prefers-reduced-motion: reduce) {
  :root {
    --transition: none;
    --tran-all: none;
  }
}
```

**Why:** `_properties.scss` declares `--transition` and `--tran-all` as named
transition tokens. Components that reference these tokens do not automatically
collapse under `prefers-reduced-motion` — the element-level reset in
`_reset.scss` only targets `animation-duration` and `transition-duration` on
`*`. P3 ensures the token values themselves are zeroed so token-aware
components also respect the user preference.

This block is appended **outside** `@layer foundation` so it applies
unconditionally regardless of cascade layer specificity.

### P4 — `@layer foundation { … }` wrapper

The entire compiled CSS from the SCSS sources is wrapped in
`@layer foundation { }`. The `foundation.css` file also declares the full
layer order at the top:

```css
@layer foundation, components, utilities, theme;
```

**Why:** Without a layer declaration, import order determines cascade
priority — which bundlers can silently reorder. With named layers, the
priority is explicit and order-independent: **theme > utilities > components >
foundation**. Consumer projects must place the theme files (`light.css` /
`dark.css`) and utility files in `@layer theme` and `@layer utilities`
respectively.

The declaration `@layer foundation, components, utilities, theme;` is emitted
before the `@layer foundation { }` block so it registers the order even if
only `foundation.css` is loaded.

## Manual refresh workflow

Run these commands from the repo root when pulling a new upstream tag.

### 1. Fetch updated SCSS files

For each file, run:

```bash
# Example for _globals.scss — repeat for each file in the tree
gh api "repos/shawn-sandy/acss/contents/packages/fpkit/src/sass/_globals.scss?ref=<new-sha>" \
  --jq '.content' | base64 -d \
  > plugins/acss-kit/assets/foundation/sass/_globals.scss
```

Files to refresh (17 total):

```
sass/_reset.scss
sass/_layout.scss
sass/_type.scss
sass/_properties.scss
sass/_globals.scss      ← re-apply P2 after refresh
sass/_elements.scss
sass/_grid.scss
sass/_columns.scss
sass/_mixins.scss
sass/_loading-animation.scss
sass/_styles.scss
sass/tokens/_color-primitives.scss
sass/tokens/_color-semantic.scss
sass/styles/_shadows.scss
sass/styles/_colors.scss
```

Project-authored files (do NOT overwrite):
```
sass/_index.scss              ← P1 applied here
sass/tokens/_index.scss       ← P1 applied here
```

### 2. Re-apply patches

- **P1** is already encoded in both `_index.scss` files — verify
  `_color-semantic` is still absent after any edits.
- **P2** — re-add `color: var(--color-text, #212529)` to the
  `h1, h2, h3, h4, h5, h6` block in `_globals.scss`.

### 3. Recompile

```bash
cd plugins/acss-kit/assets/foundation
npx sass --style=expanded --no-source-map \
  sass/_index.scss:_foundation_raw.css
python3 ../../scripts/wrap_foundation_layer.py \
  _foundation_raw.css foundation.css
rm _foundation_raw.css
```

### 4. Update this file

Update the upstream SHA and version in the table at the top. Re-run
`tests/run.sh` to confirm structural checks pass.
