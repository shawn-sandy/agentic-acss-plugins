# acss-utilities — Deprecated (v1.0.0)

> **This plugin is tombstoned.** All utility-class commands are now part of `acss-kit` v1.0.0.
>
> Existing installs continue to work, but no new features will be added here.

## Migrate

See [`plugins/acss-kit/docs/migration-v1.md`](../acss-kit/docs/migration-v1.md) for the full migration guide.

**TL;DR:**

```text
/plugin uninstall acss-utilities@shawn-sandy-agentic-acss-plugins
/plugin update acss-kit@shawn-sandy-agentic-acss-plugins
```

No CSS class names changed. Your `utilities.css` and `token-bridge.css` files work without modification.
